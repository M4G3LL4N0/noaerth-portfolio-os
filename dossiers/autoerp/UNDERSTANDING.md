# autoerp

## What is this?
AutoERP is a browser prototype that maps where finance, HR, procurement, and inventory stall.

## Who is it for?
Operators sketching an ERP rollout before buying a large system.

## Problem
ERP sprawl multiplies a bottleneck that was never mapped.

## What exists
Main is still the homepage. Branch portfolio/autoerp/workspace-recovery runs the six-input operating-map model in the browser. Prisma and the rest of the dirty index stay off that branch.

## Distinctive
It shows the planner inputs instead of a generic ERP feature grid.

## Maturity
Prototype

## Primary workflow
Describe the company shape and read an operating map. It is not a live ERP replacement.
